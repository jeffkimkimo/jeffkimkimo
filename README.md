## 📐 WHAT I ACTUALLY BELIEVE

**1. Compute is the new film stock.** It gets cheaper every year, and the people who understood that early made things nobody else could.

**2. Constraints are not the enemy of the work — they *are* the work.** Nolan shoots practical because the limit makes the frame honest. Same reason I'd rather write the function than import the library.

**3. Build in public, iterate in public, be wrong in public.** The fastest way to a good idea is a hundred committed bad ones.

**4. The best tools disappear.** If you're thinking about my software while you use it, I've failed.

**5. Ship the thing.** Taste is a filter, not a permission slip.
