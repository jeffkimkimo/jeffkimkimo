## 📐 &nbsp;WHAT I ACTUALLY BELIEVE

<table width="100%">
<tr><td width="46" align="center"><b>01</b></td><td><b>Compute is the new film stock.</b> It gets cheaper every year, and the people who understood that early made things nobody else could.</td></tr>
<tr><td align="center"><b>02</b></td><td><b>Constraints aren't the enemy of the work — they <i>are</i> the work.</b> Nolan shoots practical because the limit makes the frame honest. Same reason I'd rather write the function than import the library.</td></tr>
<tr><td align="center"><b>03</b></td><td><b>Build in public. Be wrong in public.</b> The fastest route to a good idea is a hundred committed bad ones.</td></tr>
<tr><td align="center"><b>04</b></td><td><b>The best tools disappear.</b> If you're thinking about my software while you use it, I've failed.</td></tr>
<tr><td align="center"><b>05</b></td><td><b>Ship the thing.</b> Taste is a filter, not a permission slip.</td></tr>
</table>
